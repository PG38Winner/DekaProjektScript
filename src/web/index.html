Daten-Maskierer

Die Datei verlässt diesen Rechner nicht. Sie wird ausschließlich im Browser verarbeitet; diese Seite lädt nichts nach und sendet nichts. Das Ergebnis ist eine Maskierung, keine zertifizierte Anonymisierung – Freitextfelder und Wertekombinationen können weiterhin Rückschlüsse zulassen.

Datei hierher ziehen oder auswählen:

Excel (.xlsx, .xlsm) und Access (.accdb, .mdb)

Bitte eine Datei auswählen.

Spalten

Angekreuzt = bleibt unverändert, wird also nicht maskiert. Alles andere wird ersetzt.

Access-Datenbanken werden nur gelesen; das Ergebnis ist eine Excel-Mappe, je Tabelle ein Blatt. Schlüssel- und Verknüpfungsspalten bleiben stehen, damit die Beziehungen zwischen den Tabellen erhalten bleiben.
